Tank Battle — это двухмерный многопользовательский танковый шутер с видом сверху, полностью созданный на Godot 4 с использованием GDScript. Игра отличается плавным управлением танком с помощью клавиш WASD, независимо вращающейся башней, которая следует за курсором мыши, стрельбой с перезарядкой, системой здоровья в 100 HP, механикой смерти и возрождения, а также счетчиком убийств. Карта представляет собой огороженную арену с препятствиями, все они отрисованы с использованием встроенных в Godot узлов Polygon2D и ColorRect — внешние ресурсы не требуются. Многопользовательский режим реализован через ENetMultiplayerPeer в Godot 4 для пиринговых соединений, позволяя одному игроку создавать комнату, а другим присоединяться по IP-адресу, с полной синхронизацией движения, стрельбы, здоровья и смерти на всех клиентах.
